# ATML Programming Assignment 3 (Fall 2026)

This repository contains the code and compact experimental evidence for Programming Assignment 3 of the Advanced Topics in Machine Learning (ATML) course, offered in Fall 2026.

The three independent tasks have stepwise notebooks and instructions: [mathematical fine-tuning](Task_1/README.md), [visual grounding](Task_2/README.md), and [test-time computation](Task_3/README.md). Their `main_task_*.ipynb` notebooks read the saved results when run locally, without repeating training or model evaluation.

Git includes source code, configuration, compact metrics, and report figures. Downloaded data, model weights, recovery checkpoints, and large raw predictions stay local.
